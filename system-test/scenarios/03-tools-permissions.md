# T03 — Tools и permissions

**Что проверяем:** Bash/Read/Write/etc. tools работают, approve-modal
показывает все 5 опций (Раз / Сессия / Команда / Всегда / Отклонить),
выбор запоминается соответствующей gran-ю.

## Шаги (на source где наши tools работают — ExecAI/Z.ai/Anthropic)

1. `/source execai`
2. Послать: `Создай файл /tmp/sysio-test.txt с текстом "hello"`
3. **Approve modal:** появляется, видны 5 опций. Tab/Shift+Tab двигают
   фокус, Enter принимает.
4. Выбрать **Раз** → tool отработал, файл создан. Послать ещё раз
   что-то с Write — modal появляется СНОВА.
5. Выбрать **Команда** на Bash `ls /tmp` → modal больше не появляется
   именно для `ls /tmp`, но появится для `ls /home`.
6. Выбрать **Сессия** на Read → больше не появляется для Read в ЭТОЙ
   сессии, но появится после перезапуска CLI.
7. Выбрать **Всегда** на Bash → пишется в `~/.config/execai/` (или
   аналог), сохраняется между запусками.
8. **Отклонить** на одном из вызовов → tool возвращает ошибку "user
   denied", агент это видит и реагирует адекватно.

## Pass-criteria
Все 5 уровней granularity работают как заявлено.
