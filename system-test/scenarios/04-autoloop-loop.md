# T04 — Autoloop (schedule_wakeup) + фиксированный /loop

## A. schedule_wakeup

1. `/source execai`, `think:max`
2. Послать: `Проверь /tmp/log.txt каждые 60 секунд 3 раза подряд,
   доложи если что-то меняется.`
3. **Проверка:**
   - Агент вызывает `schedule_wakeup(delay_seconds=60, prompt_on_wake=...)`
   - В status bar появляется индикатор "wakeup in 60s" (или подобный)
   - Через ~60 сек агент сам активируется с собственным промтом
   - Делает ещё 2 итерации
   - Останавливается когда сам решит

## B. Фиксированный /loop

1. `/loop 30` → агент стартует loop с интервалом 30 сек
2. Послать любое задание: `Логни в /tmp/loop.txt timestamp`
3. **Проверка:**
   - Каждые 30 сек агент повторяет задание
   - `/loop stop` или Ctrl+C останавливает loop
   - Loop НЕ продолжается после рестарта CLI (это feature)

## Pass-criteria
Обе модели loop работают, не конфликтуют между собой, корректно
показываются в UI.
