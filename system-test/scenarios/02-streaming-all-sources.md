# T02 — Streaming во всех 4-х source

**Что проверяем:** text deltas, thinking deltas, tool calls корректно
парсятся для каждого source.

## Шаги для каждого source (ExecAI / zai / anthropic / claude-cli)

1. `/source <name>`
2. Послать: `Объясни кратко (2-3 предложения) что такое quicksort.`
3. **Проверка:**
   - Текст появляется по словам/чанкам, не одним блоком в конце
   - Нет смятых символов в UTF-8 границах
   - В status bar после ответа `tokens: <число>` обновился
4. С `think:high` или `max`: послать вопрос требующий рассуждения,
   например `Что больше: 9.11 или 9.9?` — должны идти thinking deltas
   (reasoning сегмент с другим стилем) ДО основного ответа.
5. Послать: `Запусти команду ls -la в текущей директории и покажи что
   там` → проверяем что tool_use идёт через корректный механизм:
   - ExecAI/Z.ai/Anthropic — наш Bash tool с approve modal
   - claude-cli — он сам решает (наш execai-tools НЕ работает, это
     задокументировано как ограничение)

## Pass-criteria
Все 4 source отстримили текст, thinking (где доступно), tools (где
применимо) без visual-багов.
