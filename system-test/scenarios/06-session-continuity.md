# T06 — Session continuity

**Что проверяем:** перезапуск CLI продолжает последнюю беседу если
она свежая (<24ч) и в той же CWD.

## Шаги

1. `execai` → послать `Меня зовут Артём, запомни`
2. Получить ответ.
3. Ctrl+D (или /exit) → CLI закрывается.
4. `execai` снова → должно продолжить последнюю сессию (видны прошлые
   сообщения в viewport).
5. Послать: `Как меня зовут?` → ответ: "Артём".
6. **Edge case:** `cd /tmp && execai` → не должно продолжить старую
   сессию (другая CWD), стартует пустая.
7. **Edge case (≥24ч):** руками поправить mtime файла сессии на
   25+ часов назад, перезапустить → новая пустая сессия.

## Pass-criteria
Continuity работает в same-CWD < 24ч, отключается в edge case'ах.
