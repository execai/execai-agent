## Блокер: aicore-vbai R5.14 на стейдже не регистрирует свои маршруты

Демон получает задачу, начинает выполнять и падает на
`401 от /aicore-vbai — {"error":"No authorization header provided"}`.

Диагностика (по признаку из `internal/gateway/registration.go`):

| Контур | `POST /aicore-vbai/agent-stream` без токена | Значит |
|---|---|---|
| dev | `No authorization header provided` | маршрут **есть** |
| stage | `Invalid Authorization` | маршрута **нет в реестре шлюза** |

Причина найдена в коде, а не угадана: в теге **`vR5.14`** (стоит на стейдже)
в `app/main.py` **вызова саморегистрации нет вообще** — 64 строки лога старта,
ни одной про gateway. В текущем коде на этом месте стоит комментарий
`!!! НЕ УДАЛЯТЬ !!!` — это фикс инцидента 30.07.2026, который на стейдж не
доехал. Рестарт пода не помогает: регистрировать нечему.

**Чинится промоутом aicore-vbai R5.14 → R5.17.** Не делал: это чужой сервис,
и на стейдж уехали бы 3 релиза чужой работы. Решение за владельцем.
