## Что нового

### Каталог Z.ai стал живым

Список моделей Coding Plan больше не зашит в бинарь: агент спрашивает
`api.z.ai/api/anthropic/v1/models` (раз в сутки и при подключении) и
дописывает в каталог всё, что появилось на аккаунте после сборки —
glm-5.3 и glm-5.3-flash видны уже сейчас, следующие версии появятся
сами, без обновления агента.

Попутно починен фоновый рефрешер списков: раньше он спрашивал всех
провайдеров одним способом, и для Z.ai/Anthropic с настройками по
умолчанию запрос уходил не на тот адрес — живой список не обновлялся
никогда.

Встроенный запасной каталог (на случай недоступной сети) тоже обновлён:
glm-5.3 — модель по умолчанию для источников zai и zai-api.

### Windows-установщик снова ставит свежее

`install.ps1` в stable-канале был прошит на ветку R5 и ставил R5.160 —
переведён на канал stable; установщики теперь обновляются в бакете при
каждом релизе автоматически.

*(Примечание: релиз v6.78 по ошибке был собран без фикса каталога —
эта версия его действительно содержит.)*
