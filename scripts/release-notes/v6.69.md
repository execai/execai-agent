## Что нового

### OpenRouter — одиннадцатый источник

`/connect openrouter sk-or-…` — один ключ на всех вендоров: Claude, GPT, Gemini,
Kimi, GLM, DeepSeek, Qwen и остальные четыреста моделей их каталога. Список
тянется с их API при подключении; семейства, которыми реально кодят, идут
сверху, batch-варианты отфильтрованы.

### Каталог моделей стал живым у всех источников

Раньше на вопрос «какие модели у источника» отвечали дважды и по-разному:
терминал — с именами, протокол редактора — сырыми ID с сервера. В панели
плагина из-за этого был странный список без имён. Теперь каталог строит один
пакет для терминала, редактора и фонового режима.

Заодно исчезли частные дыры:

- **Kimi Code** игнорировал живой список — новинки плана (например `k3-256k`)
  не появлялись никогда, а апгрейд плана не подхватывался;
- **Anthropic** был зашит в код — новая Claude приезжала только с новой версией
  агента. Теперь спрашивается `/v1/models`;
- **Ollama** в панели показывала облачный список вместо реально скачанных
  моделей. Теперь `/api/tags`;
- список перезапрашивается раз в сутки — и в терминале, и в панели.

### Подключение источника — один путь для терминала и панели

`/connect` из панели редактора сохранял только ключ: без endpoint, без проверки
и без списка моделей. Подписка выглядела подключённой, а работала наполовину —
у OpenRouter показывалось 8 моделей вместо 415. Теперь обе поверхности проходят
один путь и отвечают одинаково.

### Поиск по памяти, включая чужую

```
/memory find тарифы
```

Ищет в своей памяти, а если там пусто — в памяти других агентов на этой машине
(каталог проекта Claude Code, его глобальная папка, `CLAUDE.md`) и предлагает
забрать находки к себе. Молча ничего не копируется.

### Имена источников на экране

`kimi` → **Kimi Code**, `kimi-api` → **Moonshot**, `zai` → **Z.ai Coding Plan**,
`zai-api` → **Z.ai API**. Идентификаторы не менялись — они в конфигах и в том,
что вы печатаете в `/connect`.
