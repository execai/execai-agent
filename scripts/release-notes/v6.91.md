## Что нового

### Списки моделей — от самих провайдеров

Раньше у большинства источников список моделей был вшит в агента и
отставал от жизни: Codex CLI предлагал gpt-5 / o3 / o4-mini, когда на
аккаунте уже были GPT-5.6 Sol / Terra / Luna, а Kimi K2.8 называлась
«K2.7 Code».

Теперь встроенных списков нет вовсе. Каждый источник спрашивает модели у
провайдера:

- Z.ai, Kimi Code, Moonshot, Anthropic, OpenAI, OpenRouter — `/models` с
  твоим ключом, с названиями, которые даёт сам провайдер;
- Ollama — то, что скачано в локальный раннер или доступно аккаунту ollama.com;
- Claude Code CLI — у самого `claude` (модели твоего плана и версии CLI,
  токены на это не тратятся);
- Codex CLI — у `codex app-server` (модели твоего плана ChatGPT, его модель
  по умолчанию — первой).

Список запрашивается при `/connect`, раз в сутки обновляется в фоне и
хранится для работы без сети. Новая модель в плане появляется в тот же
день, пропавшая — исчезает. Embeddings, речь, картинки и модерация в
выбор модели больше не попадают. Если провайдер не перечисляет нужную
модель, `/model <id>` возьмёт её как написано и запомнит.

### Свой провайдер: `/connect custom`

Подключается любой сервер с API в стиле OpenAI (`/chat/completions`) или
Anthropic (`/v1/messages`): локальные LM Studio, vLLM, llama.cpp, LiteLLM,
корпоративный шлюз, DeepSeek, Groq и другие.

```
/connect custom
```

Агент спросит по шагам: имя, тип интерфейса, адрес, ключ (можно без
ключа). Если сервер не отдаёт список моделей — спросит их ID. Esc
отменяет. Ключ остаётся на машине и в историю ввода не попадает.

Одной строкой:

```
/connect custom "LM Studio" openai http://localhost:1234/v1
/connect custom corp anthropic https://llm.corp.local sk-XXXXX --header "X-Tenant: dev"
/connect custom vllm openai http://gpu-box:8000 --models qwen3-coder,llama-4
```

Из имени получается id источника: `/source lm-studio`. Полный URL из
документации тоже подходит; нужен ли адресу `/v1`, агент выясняет у
сервера. В панели редактора (плагин 0.2.35, ExecAI Studio 0.1.46) то же
самое: **Подключить источник → Свой провайдер**.

### Мелочи

- Строки `/connect …` с ключами больше не сохраняются в истории ввода.
- Списки источников в меню больше не перемешиваются между открытиями.
- Z.ai open platform спрашивается по правильному пути `/api/paas/v4/models`.
