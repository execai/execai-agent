## Что нового

### Claude Code CLI видит картинки и скриншоты

Через источник `claude-cli` картинки до модели не доходили: история
передавалась в Claude Code одним текстом, и вместо скриншота там стояла
заглушка `[image]`. Claude знал, что картинка есть, и пытался найти её
сам — перебирал файлы в каталоге и в `/tmp` и отвечал по первой
попавшейся. Вставленный из буфера скриншот лежит вне проекта, поэтому
найти его было нельзя вовсе.

Теперь картинки уходят в Claude Code настоящими изображениями, на своих
местах в разговоре — из терминала, из панели редактора и в чатах,
открытых из истории. Чтобы длинный чат со скриншотами не раздувал каждый
запрос, заново отправляются 20 последних картинок.

### Codex CLI тоже получает картинки

У источника `codex-cli` была та же беда — теперь картинки передаются ему
файлами через `--image`. А если codex не залогинен, вместо безликого
«пустой ответ» агент показывает причину из его вывода (например,
`401 Unauthorized` — значит, нужно `codex login`).
