## execai R6.58 — the editor picks up where you left off

### Continue the last chat

The extension panel used to open on a clean slate. The conversation was never lost —
it lives in the same session store the terminal uses — but you had to dig it out of the
history by hand. An editor is a place you come back to, so the chat now comes back with
you: opening the panel continues the last chat **of that project**.

New IDE-protocol command `resume_last`. It restores the agent's history, not just the
transcript on screen: the next message you send carries the whole conversation to the
model. Turn it off with `execai.resumeLastChat` in the extension, or trigger it by hand
from «Continue the last chat» in the `>_` menu.

In the terminal this has always been `/resume` — same store, same chats, either side.

curl -fsSL https://raw.githubusercontent.com/execai/execai-agent/main/install.sh | sh
