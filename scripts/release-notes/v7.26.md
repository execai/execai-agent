## What's new in 7.26

**The Month plan now includes sync and tasks from the web chat and the phone, alongside the Work and Max plans.**

- **Sync between your computers** — memory, settings, permissions,
  provider keys and projects (`/sync on`) — works on the Month plan too.
- **Tasks from the web chat and the phone** reach your computer on the
  Month plan too: in `execai serve`, in the editor panel (VS Code, Cursor,
  ExecAI Studio) and in `execai ui`.
- Every message that lists these plans now names Work, Max and Month, in
  all five interface languages: the `/sync` help and refusal, `/start`,
  `/machine`, `/phone`, `/plan` and a task from the web that is refused.
- The editor panel and `execai ui` show the Month plan by its own name; it
  used to appear as Start.

The editor extension and ExecAI Studio are updated together with this
agent; the updated extension offers to update the agent it runs to 7.26.

**Where it was tried.** This release was tried on Linux. On Windows and
macOS it is built, but not tried on real machines.

**If you are updating from 7.15 or earlier,** read the notes of
[7.21](https://github.com/execai/execai-agent/releases/tag/v7.21) first: it
fixed a sync fault that could erase a project's memory on all your
computers. Update every computer that syncs.
