# Панель агента в браузере — `execai ui`

- **Что это.** Та же панель чата, что в VS Code и ExecAI Studio, во вкладке браузера: чаты, разрешения, модели и источники, задачи с сайта. Редактор не нужен — достаточно браузера на этом компьютере.
- **Запуск.** `execai ui` в каталоге проекта (или `execai ui --cwd DIR`): печатает адрес и открывает браузер; `--no-open` — только напечатать адрес, `--port N` — свой порт. Остановить: Ctrl+C — закрытие вкладки агента не останавливает.
- **Безопасность.** Слушает только 127.0.0.1. В адресе одноразовый ключ из 32 байт: при первом заходе он меняется на cookie HttpOnly SameSite=Strict, и повторно ссылка из терминала ничего не откроет. Запросы с других сайтов и других имён хоста отклоняются, страница не может обратиться никуда, кроме этого агента, а вход в ExecAI до неё не доходит.
- **Файлы**, приложенные в браузере, сохраняются в `.execai/uploads/` проекта; синхронизация проекта их не отправляет.
- **По SSH:** `ssh -L 8765:127.0.0.1:8765 host`, там `execai ui --port 8765 --no-open`, а напечатанную ссылку открыть у себя.
